# Shinobi Legacy 2

Pre-alpha three.js slice: character models and camera system. The Shinobi Legacy
archive build lives playable under `/classic`.

- three.js r160, vendored in `/lib` (no CDN dependency)
- controls: WASD move, drag to orbit, scroll to zoom, 1/2/3 camera presets
  (follow, shoulder, cinematic)
